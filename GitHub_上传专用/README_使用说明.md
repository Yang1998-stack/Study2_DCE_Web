# Study 2 燕麦饮实验平台

**启动实验：双击本目录的「一键启动_本地演示.bat」。**

浏览器打开 http://127.0.0.1:8000 。使用期间保持启动窗口打开；关闭窗口即可停止。需要 Python 3.10 或更新版本。

- **后台**：http://127.0.0.1:8000/admin 。首次使用先运行「管理工具/设置_研究者账号.bat」。
- **同步、导出与预测试**：打开「管理工具」文件夹，选择对应按钮。
- **QuickForm和网上发布**：[连接与发布说明](docs/QuickForm_接入和查看数据.md)。
- **详细说明**：[平台使用说明](docs/平台使用说明.md)。
- **设计与编码**：[1 L新版设计诊断](docs/design_v2/DCE设计诊断报告.md)。

当前为演示/预测试候选版本。正式收数仍被锁定，需确认设计并完成预测试。

代码放在 app，设置放在 config，页面放在 static，题目放在 designs。原始答卷及备份保存在 data，导出在 exports，源码压缩包在 dist；这些文件夹请保留。
