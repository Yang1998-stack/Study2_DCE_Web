## 已知需修订事项
1. 本版广告与DCE商品规格均为1 L，购买任务采用15/24/34元候选价格。需对新价格、家庭购物情境及商品信息做预测试，研究者确认新设计前不得正式收数。
2. 温室气体图表3.2对0.9，对应减少71.875%，整百分数应约72%，目前图片标71%。
3. 土地使用图表9.0对0.8，对应减少91.111%，标91%准确。
4. 3.2/0.9kg CO2e及9.0/0.8m²是乳与燕麦饮品的行业/全球估计示例，必须注明出处且不可暗示为PureOat品牌LCA测量。参见 https://ourworldindata.org/environmental-impact-milks 。
5. “SOURCE OF FIBER”“NO ADDED SUGAR”需有可核验营养/配方支持。
6. 两图文字与产品基本一致，但产品的左右位置、背景色调及信息密度存在变化，需要预实验控制非目标特征。
